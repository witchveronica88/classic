# 🎼 클래식

클래식 공연 관람 기록과, 시대 · 작곡가 · 연표 · 사전으로 정리한 클래식 공부 노트를 담은 정적 웹 페이지입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 구성

### 공연 기록
- 공연별 출연진 · 프로그램 해설 · 협연자 소개 · 좌석/예매 정보 · 예습 영상 링크
- 날짜에 따라 **다가오는 공연 / 관람한 공연**으로 자동으로 나뉘고, 다가오는 공연에는 D-day 표시
- 관람 요약(들은 작품 · 만난 연주자 · 감상 노트 수). 칸을 누르면 항목마다 한 줄짜리 목록이 펼쳐지고, 목록에서 고르면 그 공연의 곡 · 연주자 · 감상 노트로 이동
- **감상 노트**: 관람을 마친 공연의 메모를 손글씨체(나눔바른펜)로, 별점은 노트 맨 위에 따로 보여 줌. 화면에서 입력하지 않고 `index.html`에 직접 적음(아래 '내용 추가하기')
- **캘린더에 추가**: 예정 공연을 `.ics` 파일로 받아 휴대폰 · 구글 캘린더에 등록

### 클래식 공부
- **시대 · 작곡가**: 중세 · 르네상스부터 근현대까지 6개 시대를 탭으로 골라 카드 하나씩 봄. 카드마다 시대 특징 · 먼저 들어 볼 곡 · 작곡가 · 음악사 연표를 ＋로 펼쳐 봄 (작곡가 66명, 연표 57개 사건)
- **클래식 사전**: 곡의 종류 · 작곡 기법 · 사조 · 연주와 편성 · 공연 관람 · 읽는 법까지 6개 분류를 탭으로 골라 카드 하나씩 봄. 하위 분류와 용어를 ＋로 펼쳐 봄
- **통합 검색**: 시대 · 작곡가 · 대표곡 · 연표 · 사전 항목 (`/` 키로 바로 검색, ↑↓ · Enter로 이동)

### 듣기 (난처한 클래식)
- 「난처한 클래식」 1~10권의 스피커 번호별 수록 음악 727곡을 권 탭으로 골라 봄 (난톡 게시판에서 모은 유튜브 링크)
- 권 카드마다 ★ 중요곡과 스피커 번호 10개씩 묶음을 ＋로 펼침. 곡마다 한 줄로, 앞의 번호를 누르면 난톡 원글, 곡 이름을 누르면 유튜브가 열림
- 중요곡 모음 원글 · 중요곡 재생목록 링크는 ★ 중요곡 안에 있음
- 작곡가 카드의 "난처한 클래식" 링크로 해당 권으로 이동, 통합 검색으로 곡 이름 검색

### 그 밖에
- 기기 설정을 따르는 다크 모드
- 모바일 우선 레이아웃, 화면 아래 고정 탭 바(공연 기록 · 시대 · 작곡가 · 클래식 사전 · 듣기), 맨 위로 버튼
- `#eras`, `#dictionary`, `#listen`, `#composer-beethoven`처럼 주소 끝에 붙여 원하는 화면으로 바로 이동

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 · 스타일 · 동작, 공연 기록 내용 |
| `study-data.js` | 시대 · 작곡가 · 연표 · 사전 데이터 (`window.CLASSIC_STUDY_DATA`) |
| `listening-data.js` | 난처한 클래식 수록 음악 목록 (`window.CLASSIC_LISTENING_DATA`) |
| `tools/import-nanclassic.py` | 난처한 클래식 수록 음악 HTML을 `listening-data.js`로 바꾸는 도구 |
| `icon.svg` | 파비콘 |

### 내용 추가하기
- **공연**: `index.html`의 `<article class="record" data-date="YYYY-MM-DD" ...>` 블록을 복사해 고치면 됩니다. 상태와 개수는 자동으로 계산됩니다.
- **감상 노트**: 그 공연의 `공연 정보` `<details>` 바로 앞에 아래 블록을 넣습니다. 문단은 `<p class="note-text">`를 하나씩 더하고, 줄바꿈은 그대로 보입니다. 별점은 `<article>`에 `data-rating="1~5"`를 붙입니다(없으면 표시 안 함).
  ```html
  <details class="note-detail">
    <summary><span>감상 노트</span></summary>
    <div class="detail-body"><p class="note-text">메모</p></div>
  </details>
  ```
- **작곡가 · 연표 · 용어**: `study-data.js`의 `composers`, `timeline`, `terms` 배열에 항목을 추가합니다.
  - 작곡가의 `era`는 `eras`의 `name`과 같아야 하고, `together`에는 다른 작곡가의 `short` 이름을 쉼표로 적습니다.
  - 연표 항목은 `["연도", "내용", "시대 이름"]` 형식입니다. 내용에 작곡가 `short` 이름이 있으면 자동으로 링크가 걸립니다.
  - 사전 용어는 `{ "category", "name", "description"(한 줄 정의), "detail"(자세한 설명, 문단은 빈 줄로 나눔), "listen"(들어 볼 곡, 선택) }` 형식입니다. 악기 · 편성 · 작품번호 항목은 `["이름", "한 줄 정의", "자세한 설명"]`입니다.
  - 시대의 `background`는 '시대 배경'에 나오는 문단 목록입니다.
  - `study-data.js`를 고친 뒤에는 `index.html`의 `study-data.js?v=` 숫자를 하나 올립니다.
  - 시대별 **먼저 들어 볼 곡**은 `eras[].listen`에 곡마다 `{ "text": "곡 이름", "url": "", "why": "" }`로 적습니다. `url`에 영상 주소를 넣으면 그 곡이 링크가 되고, `why`에는 왜 먼저 들으면 좋은지 한 줄로 적습니다(마침표 없이).

- **난처한 클래식 목록 갱신**: 「수록 음악 듣기」 HTML을 새로 모았다면 `python3 tools/import-nanclassic.py 파일.html listening-data.js`를 실행하고 `index.html`의 `listening-data.js?v=` 숫자를 하나 올립니다. 권과 작곡가 연결은 도구 안의 `BOOK_COMPOSERS`에서 정합니다.

## 저장 범위
